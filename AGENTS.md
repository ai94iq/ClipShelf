# Agent instructions (Copyloft)

## Hard rules

- **Never modify the user's system without explicit approval in the current conversation.**
  Registry, Explorer, services, OS settings, network/VPN state, and other
  applications' data are read-only by default: inspect, report, propose the
  exact change, and wait for a yes. Building, running, stopping, and testing
  the project under development is normal work. A debugging theory never
  justifies a system change.
